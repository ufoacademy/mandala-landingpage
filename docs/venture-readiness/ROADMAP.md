# 건강만다라 벤처 적합화 로드맵

## 목표

건강만다라를 단발성 자가진단 페이지가 아니라 다음 과정을 재현하고 검증할 수 있는 생활습관 변화관리 시스템으로 발전시킨다.

1. 검진·생활습관 데이터 입력
2. 8영역 점수 표준화
3. 건강신호–습관의 다대다 매핑
4. 설명 가능한 우선행동 선정
5. SMART 목표 실행
6. 4주 재진단과 변화량 측정
7. 개인·코치·기관 단위 성과 분석

## Phase 1 — 평가 결과의 재현성 확보

- 문항 버전, 산식 버전, 리포트 스키마 버전을 진단기록에 저장
- 4점 척도 최저 원점수(영역 8점)를 0점으로 보정하는 POMP 0~100 표준점수 도입
- 원점수와 표준점수를 함께 보존
- 4단계 상태를 취약(0~24), 주의(25~49), 보통(50~74), 강점(75~100)으로 통일
- 진단 시작·완료 시각과 이용 모드를 기록
- 레이더차트와 리포트가 표준점수를 사용하도록 통일

> 기존 기록은 산식 버전이 없는 레거시 자료로 구분한다. 신규 결과와 점수 자체를 직접 비교하지 않고 원응답을 새 산식으로 재계산한 후 비교한다.

## Phase 2 — 설명 가능한 우선순위 엔진

우선행동은 단순 최저점 한 개가 아니라 다음 요소를 분리해 계산한다.

- 습관 취약도
- 입력된 검진신호와의 연계강도
- 행동의 수정 가능성
- 이용자의 준비도
- 안전 게이트(의료기관 확인이 먼저 필요한 경우)

결과 화면에는 선정된 행동과 함께 '왜 이 행동이 먼저인지'를 데이터 근거로 표시한다. 규칙 테이블은 코드와 분리하고 버전 관리한다.

## Phase 3 — 행동실행·재진단 루프

- 우선영역별 SMART 목표 1개 선택
- 시작일, 빈도, 시간, 장애물, 대체행동, 확인방법 저장
- 1주·2주·4주 실천 체크
- 4주 재진단을 최초 진단 ID와 연결
- 영역별 변화량과 목표 달성률 자동 계산
- 코치가 다음 행동을 승인·수정·보류할 수 있는 기록

## Phase 4 — 코치·기관 대시보드

- 이용자별 진단 이력과 재진단 비교
- 기관별 완료율, 재진단율, 목표설정률, 실천기록률
- 개인정보를 제거한 집단 변화 통계
- CSV/PDF 성과보고서
- 코치 계정, 권한, 접근로그, 데이터 다운로드 이력

## 벤처 신청용 핵심 증거지표

| 구분 | 지표 | 산출 방식 |
|---|---|---|
| 기술 재현성 | 버전기록률 | 버전 3종이 저장된 진단 / 전체 신규 진단 |
| 제품 안정성 | 리포트 성공률 | 성공 리포트 / 생성 요청 |
| 사용자 실행 | 목표설정률 | SMART 목표 저장 사용자 / 진단 완료 사용자 |
| 지속성 | 4주 재진단율 | 4주 재진단 사용자 / 최초 진단 사용자 |
| 행동성과 | 목표 달성률 | 완료 체크 / 계획된 실천 |
| 변화성과 | 영역점수 변화 | 동일 산식의 4주 점수 - 최초 점수 |
| 기관확장성 | 기관·코치 수 | 실제 발급·운영 계정 수 |

## 신청 전 필수 검증

- 64문항 내용타당도 검토 기록
- 내부일관성 및 문항분석
- 테스트–재테스트 신뢰도
- 사용자 사용성 평가
- 의료적 진단으로 오해될 수 있는 문구 검수
- 개인정보·건강정보 처리 흐름과 보유기간 검증
- 점수 산식, 검진 기준, 근거문헌의 변경이력 관리
