# 완료한 검사에서 프리미엄 리포트 다시 생성하기

검사를 완료하면 문항 응답과 입력한 검진 수치가 `진단기록` 시트의 같은 검사 ID에 저장된다. 리포트 생성이 실패했거나 건너뛰었어도 다시 64문항을 답할 필요가 없다.

1. [건강만다라 진단 웹](https://mandala-gamma.vercel.app/) 첫 화면에서 검사 당시 이름, 휴대폰 번호, **그 검사별 인증코드**를 입력한다. 앱 가입용 문자 인증번호는 사용하지 않는다.
2. 개인정보와 건강정보 처리에 각각 동의하고 **완료한 검사로 리포트 생성하기**를 누른다.
3. 저장된 결과 화면에서 **프리미엄 AI 리포트 생성하기**를 누른다. 검사 당시 이메일이 비어 있다면 리포트 수신 이메일을 입력한다.
4. 이미 리포트가 저장되어 있으면 기존 결과서를 바로 연다. 새 리포트 생성에 실패해도 이 단계를 다시 시도할 수 있다.

코드를 잊었거나 만료되었다면 건강이음센터 담당자는 원본 시트의 **검사 신청 → 인증코드 재발급**에서 **같은 신청ID**의 코드를 갱신해 문자로 전달한다. 새로운 검사를 등록하면 새 검사ID가 생기므로 기존 검사 복구에는 사용하지 않는다. 재발급하면 이전 코드는 즉시 무효가 된다.

운영 점검: `recover_diagnosis`는 완료된 초대 코드와 이름·휴대폰을 검증하고 해당 신청ID에 묶인 진단 한 행만 읽는다. 서버는 2시간짜리 HttpOnly 진단 권한 쿠키를 발급하며 코드 원문을 저장하거나 응답에 넣지 않는다. 운영 Apps Script 배포 버전 17부터 지원한다.
